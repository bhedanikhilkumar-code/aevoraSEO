# Google Business Profile Optimization

This file defines AevoraSEO's Google Business Profile workflow for local SEO.

GBP can drive calls, directions, bookings, and local trust. For many local businesses, website SEO and GBP must work together.

---

## 1. When to Use

Use this file for:

```text
local businesses
clinics
dentists
doctors
law firms
gyms
restaurants
real estate offices
service-area businesses
agencies with local leads
```

---

## 2. GBP Audit Inputs

Ask for or inspect:

```text
Business name
GBP URL or screenshot
Primary category
Secondary categories
Services/products
Business description
Address/service area
Phone
Website link
Appointment link
Opening hours
Photos
Posts
Q&A
Reviews
GBP insights if available
UTM-tagged links
Competitor GBP profiles
```

If GBP access is unavailable, say:

```text
GBP performance is not verified. For local lead generation, this is a major missing data source.
```

---

## 3. Core GBP Checks

Check:

```text
Primary category matches highest-value service.
Secondary categories cover real services.
NAP is consistent with website/citations.
Website and appointment links work.
Business description is service + location focused.
Services are fully filled.
Photos are recent and real.
Reviews are active and relevant.
Q&A answers common buyer questions.
Posts are used for updates/offers/content.
UTM tracking exists.
```

---

## 4. Category Strategy

Primary category should match the main local intent.

Examples:

```text
Dentist
Dental Clinic
Emergency Dental Service
Orthodontist
Medical Clinic
Law Firm
Marketing Agency
Solar Energy Company
```

Do not add inaccurate categories just for ranking.

---

## 5. Services Strategy

Services should map to SEO landing pages.

Example dental:

```text
Dental Implants
Family Dentistry
Emergency Dentistry
Invisalign
Cosmetic Dentistry
Veneers
Teeth Whitening
Tooth Extraction
Wisdom Teeth Removal
```

Example AI agency:

```text
AI Automation Consulting
AI Agents Development
Chatbot Development
SEO Audit
AI Training
Business Process Automation
```

Each major GBP service should have a matching website page where possible.

---

## 6. Review Strategy

Audit:

```text
review count
rating
review velocity
keywords inside reviews
service-specific reviews
owner responses
negative review handling
competitor review gap
```

Action:

```text
Create review request workflow.
Ask for service-specific language naturally.
Respond to all reviews professionally.
Use reviews on matching service pages.
```

Never fake reviews.

---

## 7. Photos and Posts

Check:

```text
logo
cover photo
team photos
location photos
service photos
before/after where compliant
class/event photos
project screenshots
recent posts
```

Post ideas:

```text
service spotlight
FAQ answer
case/project story
new article/course announcement
offer/event
review highlight
```

---

## 8. Q&A Strategy

Add/answer useful buyer questions:

```text
Do you offer same-day appointments?
Do you offer financing?
Which areas do you serve?
What services do you provide?
How can I book?
Do you offer online consultations/classes?
```

Answers should be honest and concise.

---

## 9. UTM Tracking

GBP links should use UTM parameters.

Recommended:

```text
?utm_source=google&utm_medium=organic&utm_campaign=gbp
```

For appointment link:

```text
?utm_source=google&utm_medium=organic&utm_campaign=gbp_appointment
```

Track:

```text
website clicks
appointment clicks
calls
form submissions
WhatsApp clicks
```

---

# Local Authority Links

This file defines safe local link-building for local SEO campaigns.

Local authority links often matter more than generic supposedly authoritative links for local service rankings.

---

## 1. Best Local Link Types

```text
Chamber of commerce
local business associations
industry associations
local sponsorships
community events
school/nonprofit sponsorship pages
local press stories
provider/manufacturer listings
local directories with real traffic
health/legal/professional profiles
partner/vendor pages
```

---

## 2. Medical/Dental Examples

```text
Chamber profile
Dental society profile
Healthgrades/Zocdoc/dental directories
implant manufacturer/provider listings
local community sponsorship
local press education story
clinic partner pages
```

---

## 3. Evaluation Checklist

```text
Is it locally relevant?
Is it niche relevant?
Is it indexed?
Is the page real and useful?
Does it have organic traffic or local trust?
Does it avoid spammy outbound links?
Can we use branded or natural anchors?
Is the price fair if paid?
```


<a id="map-pack-audit"></a>

# Map Pack Audit

This file defines how AevoraSEO evaluates local map-pack competition and opportunity.

Map-pack visibility is often the fastest path to calls for local businesses.

---

## 1. When to Use

Use for local intent keywords such as:

```text
service near me
service + city
best service + city
emergency service + city
provider type + city
```

---

## 2. Data Sources

Use:

```text
Google search/manual map checks
Dated user-provided Maps observations or exports (not collected by the website crawler)
GBP screenshots/export
Local Falcon/BrightLocal exports if provided
SERP screenshots
Competitor GBP profiles
```

---

## 3. What to Record

For each map keyword:

```text
Query
City/location
Date
Client position if visible
Top 3 businesses
Top 10 businesses
Primary categories
Ratings
Review counts
Website links
Distance/location pattern
Services shown
Ads/local service ads if present
```

---

## 4. Map Competitor Analysis

Compare:

```text
category match
review count
rating
review keywords
profile completeness
photos
posts
services
website authority
local landing page quality
citations/local links
```

---

## 5. Map Pack Gap Types

```text
Category gap
Review gap
Distance/location disadvantage
Service listing gap
Photo/profile completeness gap
Website landing page gap
Citation/NAP gap
Authority gap
```

---

## 6. Map Pack Action Plan

Actions may include:

```text
fix GBP categories
expand services
build review workflow
add service photos
publish GBP posts
answer Q&A
create matching local service pages
clean citations
build local links
add UTM tracking
```

---

## 7. Output Template

```text
## Map Pack Audit

| Query | Client Position | Top Competitors | Main Gap | Action |

### Review Gap
[summary]

### Category/Service Gap
[summary]

### Website/Local Page Gap
[summary]

### 30-Day Map Pack Plan
[exact actions]
```

---

## 8. Rule

Do not claim exact map rank unless directly checked with location/device/date or provided by a rank-grid tool.

<a id="nap-citation-audit"></a>

# NAP and Citation Audit

Audits business name, address, phone, and citation consistency.

---

## Checks

Website NAP, GBP NAP, directories, social profiles, maps, industry listings, local chambers, old addresses/phones.

## Fixes

Correct inconsistent listings, remove duplicates, build missing high-quality citations.

## Output

Citation source, NAP status, issue, action, priority.

<a id="review-strategy"></a>

# Review Strategy

Builds ethical review growth systems for local SEO and conversion.

---

## Checks

Review count, rating, velocity, keywords, recency, competitor reviews, response quality.

## Actions

Review request flow, staff SOP, QR/WhatsApp/email follow-up, response templates, service keyword themes.

## Rule

Do not fake reviews or incentivize improperly.

# Service Area SEO

SEO strategy for businesses serving multiple areas.

---

## Use Cases

Service-area businesses, agencies, clinics, real estate, home services, consultants.

## Rules

Create useful location pages only where there is real service relevance and unique proof.

## Output

Service area map, pages needed, citation plan, review/local proof plan.
